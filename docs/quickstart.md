# quickstart
Quickstart\n\nEvery request needs an `API-KEY` header.

1. Sign in at the [API Console](https://aiairouter.com/dashboard). Google sign-in is supported.
2. A default `API-KEY` is created with the account. New accounts receive 10 quota as a trial balance.
3. Send the key on every request: `API-KEY: YOUR_API_KEY`.\n\nThe full guide, including the first image request, is in the [Quickstart](https://docs.aiairouter.com/quickstart).
